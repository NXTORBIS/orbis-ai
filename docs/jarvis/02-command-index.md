# J.A.R.V.I.S. — the global command index (⌘K)

The whole searchable surface, as the app defines it: 116 destinations, each with a breadcrumb and its own keywords.
This is the model Orbis's own Command Center should be measured against — note that it indexes **query-string
destinations** (a settings tab, a file section, a task filter) as first-class results, not just pages.

### Deep links the index treats as destinations in their own right

**Settings tabs** — `?tab=appearance` (theme, dark mode, colors) · `notifications` (alerts, email) · `privacy`
(data, security) · `account` (email, password) · `ai` (model, llm, provider) · `display` (layout, sidebar).

**File sections** — `?section=` myfiles · recent · favorites · shared · trash · documents · images · videos · audio ·
code · archives.

**Task filters** — `?filter=` today · upcoming · completed · overdue.

**Reminder filters** — `?filter=` today · upcoming · completed · recurring.
